# Hasil Riset

| Lokasi | Isi |
|---|---|
| `dhompo/tables/` | Laporan peak-weighted, deep learning, prediksi A/B/C, serta tabel per eksperimen |
| `dhompo/figures/` | Tujuan output figur notebook Dhompo; dibuat saat diperlukan |
| `surabaya/tables/` | Laporan `urban`/Surabaya, residual versus persistence, dan varian delta |
| `surabaya/figures/` | Tujuan figur Surabaya jika eksperimen menyimpan figur |

Laporan merupakan keluaran lokal yang diabaikan Git. Tidak semua file yang dirujuk skrip/notebook tersedia dalam clone. Jalankan eksperimen sumber sebelum skrip pembuat tabel turunannya. Penataan folder mempertahankan file hasil yang sudah ada tanpa menghitung ulang metrik.
